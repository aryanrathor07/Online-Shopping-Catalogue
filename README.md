## Project Description
TechMart is a minimalist, responsive web-based shopping catalogue focused on laptops and computing accessories. Built using foundational web technologies, it allows users to browse categorized products, inspect key specifications, and dynamically calculate their total shopping bill.

## Key Features
- **Categorized Product Display:** Dedicated hero section for Laptops along with supporting sections for Accessories and Audio.
- **Minimalist & Clean UI:** Built using pure HTML5 semantic tags, CSS Box Model, and Flexbox for clean alignment without heavy frameworks.
- **Interactive Shopping Cart:** Simple JavaScript logic to add items to the cart, list selected products, and automatically calculate the total payable amount.
